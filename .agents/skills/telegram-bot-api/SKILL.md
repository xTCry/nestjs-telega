# Telegram Bot API и telegraf-hardened

Сверяй версию зависимости и поддерживаемую версию Bot API. Возможности Bot API,
методы библиотеки и API интеграции приложения могут различаться.

- [Telegram Bot API](https://core.telegram.org/bots/api) — методы, типы и ограничения.
- [telegraf-hardened](https://github.com/telegraf-hardened/telegraf-hardened) и
  [типы](https://github.com/telegraf-hardened/types) — реализация и типизация.
- Для возможностей Bot API 10.3 в telegraf-hardened 6.1 смотри
  [справку](references/bot-api-10.md); сверяй её с текущей версией API.
